# Crypto Wallet

Некастодиальный MVP криптокошелька.

## Важно
Это тестовый прототип. Не используйте его для хранения реальных средств. Seed-фраза создаётся в браузере и не отправляется на сервер.

## MVP
- создание Ethereum-кошелька
- импорт seed-фразы
- отображение адреса
- локальная генерация ключевого материала

Следующий этап: testnet-балансы, QR, история, отправка/получение и поддержка сетей.
