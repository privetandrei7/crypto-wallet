# USDT TRC20 Wallet MVP

Некастодиальный браузерный MVP только для USDT в сети TRON.

## Сейчас работает
- создание 12-словной seed-фразы;
- TRON-адрес по BIP44 path m/44'/195'/0'/0/0;
- импорт seed-фразы;
- баланс USDT;
- адрес для получения;
- QR-код;
- история TRC20;
- отправка USDT с локальной подписью;
- тестовая сеть TRON Shasta.

## Важно
Это тестовый MVP. Не используйте реальные средства.

Seed-фраза и приватный ключ используются в браузере и не отправляются приложением на сервер, но до Mainnet необходимы аудит безопасности, фиксация зависимостей, нормальное зашифрованное локальное хранилище и отказ от внешнего QR/CDN в пользу проверенных локально поставляемых зависимостей.

Отправка TRC20 расходует Energy/Bandwidth; в зависимости от состояния аккаунта могут потребоваться TRX для сетевых расходов.
